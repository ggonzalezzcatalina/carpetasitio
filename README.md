# Portfolio / Catalina González
Este proyecto es una web diseñada a través de HTML y CSS para presentar mi portfolio.

## Especificaciones de maquetación
-Como editor de código utilicé Visual Studio Code

-La pantalla en la que trabajé es un monitor de 15.6 pulgadas

-El ancho contenedor de diseño lo estandaricé a un ancho máximo de 1450px

-Para la tipografía utilicé la familia tipográfica Epunda Sans, en sus variantes: Regular, Medium y SemiBold para establecer jerarquias y además la Herr Von Muellerhoff

-Uso de contenedores sólidos y centralizados

-Uso de Flexbox en secciones estratégicas 

## Estructura del repositorio:
index.html: Estructura principal de la página de inicio

script.js: JavaScript para la interactividad de los slider y el menú hamburguesa del mobile

sobre-mi.html: Estructura principal de la sección "Sobre mi"

contacto.html: Estructura principal de la seccion "Contacto"

estilos.css: Hoja de estilos donde se marcan las necesidades estéticas de la página 

fonts:  (Epunda Sans y Herr Von Muellerhoff)

img: Recursos gráficos utilizados en la totalidad de la página

video: Archivo multimedia utilizado
